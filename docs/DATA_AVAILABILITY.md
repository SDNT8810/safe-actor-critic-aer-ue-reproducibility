# Data and code availability

All numerical results in the associated manuscript were generated by the code
in this repository on the common synthetic robot-navigation benchmark. No
numerical result was copied from a prior publication.

The public package includes:

- executable simulation, training, evaluation, plotting, and audit code;
- deterministic seed formulas and the complete experimental protocol;
- aggregate and seed-level CSV results used by the manuscript;
- visualization trajectories and the shared severe sensor stream;
- generated tables, figures, and animations;
- fairness, information-flow, collision-source, and no-oracle audits; and
- automated tests.

The two uncertain physical obstacles are static. Their true centers and true
clearance are evaluator-only quantities and are excluded from controller,
estimator, critic, replay-priority, and replay-buffer updates.

No human-participant, patient, confidential, or personally identifying data
are used.
